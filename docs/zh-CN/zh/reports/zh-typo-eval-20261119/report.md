## 判定

| 规则 | 结果 |
| --- | --- |
| 主指标：typo 臂（task 规则）显著高于对照的 LM 规则（阈值 3） | 32.2 对 34.3，显著更低：**未通过** |
| 护栏 1：自重打分 Top-1 不显著低于对照 | 通过 |
| 护栏 2：干净误显示不高于对照；Standard 不显著低于 v1 | 9.7 对 14.2；通过 |

数字说明：

- 错字训练让 task 模式打分学会纠错（r3-ctrl task 13.0 → typo task 32.2），但 task 模式仍低于 LM 规则。
- LM 规则下 v1、r3-ctrl 和 typo 臂的 typo @2 相同（34.0–34.3）。在这个候选池上，纠错质量与模型无关。
- 校准比模型更重要：阈值 3 时，12.6–14.2% 的干净句子会显示纠错；校准阈值（3.5–3.9）把它降到 9.2–9.5%，typo @2 只少 0.3（p ≥ 0.13）。

## 后续

- typo 臂不作为 v2-20m 候选；候选仍是 kd-cont（如果第 3 轮的臂更好则用它）。
- Vime 保留 LM 规则。`calibration.json` 记录针对发布模型、在本基准上校准的重打分 λ 和 LM 规则阈值；不设 taskScore 规则，因此不制作 taskScore 参考和 fixture。
- 第 4 轮和 800M 不加入 `typo` 数据。
- typo store 和基准保留：每个新模型都用这个基准校准阈值。

未报告：单独统计的合法拼写错字，以及私有基准（计划中的描述性项目）；它们不影响判定。
