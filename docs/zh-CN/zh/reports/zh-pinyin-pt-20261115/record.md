# zh 三任务第三组：从零联合预训练（2026-11-15）

第三组对照（`configs/zh/train-zh-pinyin-pt.toml`，stage `zh-pinyin-pt`）检验另一条路线：不在 20M 基座上续训拼音，而是从随机初始化开始，把拼音样本直接混进基座的预训练流。对照是[第二轮](../zh-pinyin-r2-20261114/evaluation.md)的 `r2-cont`（从第一轮续训）和 12K 基座 `12k-fresh-s1`（同一条 plain 流，不含拼音）。全部是 development 结果，blind 没有读，公开集的 test 没有读。

## 结论

- **20M 不适合联合预训练，继续走 `r2-cont` 的续训路线。**
- 拼音生成在两套集合上都低于 `r2-cont`。私有基准 Top-1 −2.2 个百分点（p 0.0004），全拼 −4.4；公开集全部 37.8% 对 39.6%，全拼 74.9% 对 77.3%。
- 基座能力的损失比续训小，但没有换来足够的收益：
  - Standard 重排对基座只差 −4（p 0.61），`r2-cont` 是 −24；
  - 联想轨道 A Top-3 比 `r2-cont` 高 1.1 个百分点（p 0.004），仍比 vimeml-tiny-zh-v1 低 1.7 个百分点（p 5e-5）。
- 同一份数字对 200M 不一定成立：200M 参数多、训练 token 相同，容量压力小得多。12K 联合拼音 200M 用的就是这份配方，正在训练。

## 配置

基座 20M 的配方不变：

- 数据：`12k-fresh-s1` 冻结的混合与种子。
- 学习率 cosine 6e-4 → 6e-5，warmup 1,000。
- 每次更新 512 个 LM 窗口，共 844,730 次更新。
- 模型：d_model 384、6 头、9 层、d_ff 960、SwiGLU、RMSNorm、上下文 128、词表 12,288，bf16。

在此之上，每次更新加 192 个拼音样本（全拼 48 / 混合 64 / 首字母 56 / 纠错 24），来自预训练规模的拼音 store `artifacts/training-data/zh-pinyin-pt-12k`（`configs/zh/data-zh-pinyin-pt.toml`，manifest SHA256 钉死在配置里）。loss 按 `per_kind` 归一：LM 占权重的 512/704，每种拼音样本按自己的样本份额。

## 训练

- 一次跑完 844,730 次更新，纯训练 35,251 s（9.79 h），没有中断或恢复。
- LM：432,501,627 个窗口，监督 token 14,519,248,976。
- 拼音样本：全拼 40,547,040、混合 54,062,720、首字母 47,304,880、纠错 20,273,520，约为 store 的半遍。
- 每 5% 一个里程碑，共 20 个。

最后一个里程碑（M20）与基座对比（BPC，越低越好）：

| 验证集 | 第三组 | 基座 `12k-fresh-s1` | 差 |
| --- | ---: | ---: | ---: |
| web | 4.4603 | 4.3545 | +0.106 |
| chat | 5.7230 | 5.6907 | +0.032 |
| probe | 4.4466 | 4.3404 | +0.106 |

M20 的拼音验证（每种 4,096 条，纠错 1,674 条；teacher forcing）：

| 种类 | loss | 整句完全正确 |
| --- | ---: | ---: |
| 全拼 | 0.345 | 63.9% |
| 混合 | 0.891 | 31.4% |

这组拼音验证取自预训练规模的 store，与第二轮的 v2 验证集不同，数值不能直接对比；跨组比较以下面的基准为准。

在同样的 LM 更新数下，plain BPC 比基座高约 0.1。拼音样本占了约 27% 的 loss 权重，20M 的容量被分走了一部分。

## 判读

- 联合预训练的思路是让基座从一开始就兼顾三任务，避免续训带来的遗忘。
  - 重排上确实如此：退化从 −24 降到 −4，不显著。
  - 联想上只追回了一部分：比 `r2-cont` 高 1.1，仍比 v1 低 1.7。
- 代价是拼音生成全面下降，私有基准与公开集方向一致。全拼退化最明显：私有 −4.4，公开 −2.4。
- 对 20M 来说，这笔交换不划算：拼音生成是必须的任务，重排与联想的收益太小。

## 下一步

1. 20M 保留 `r2-cont` 路线。是否做第三轮后训练，等 12K 联合拼音 200M 的评测出来再定（蒸馏或改数据）。
2. 推理期重打分（v1 先验，λ = 1.6）后第三组私有基准全部 27.7% → 35.3%、公开集 37.7% → 50.1%，与 `r2-cont` 重打分后（36.4%、51.3%）的差距缩小到约 1 个百分点，见[推理期重打分报告](../zh-pinyin-rescore-20261115/report.md)。
3. 12K 联合拼音 200M（`configs/zh/train-zh200m-12k-pinyin-pt.toml`，d1024 / L15 / c128，193,625,088 参数）用同一份数据和配方，到位后按同一流程评测。
