# v2-20m 第三轮蒸馏的 development 评测（2026-11-17）

本报告按[蒸馏计划](../../training/training-zh-kd-plan.md)第三轮的判定规则，评测四臂：`r3-ctrl`、`r3-data`、`r3-alpha`、`r3-plain`。比较对象有两个：

- 第二轮选出的候选 `kd-cont`；
- `vimeml-tiny-zh-v1`，LM 模式。

所有评测都只用 development，blind 和公开集 test 都没有读。拼音生成、Standard 和联想由 `cluster_eval_zh.sh` 跑出；自身重打分用 `pinyin_gen_zh.py reprior` 计算，先验是各臂自己的 final.pt。`kd-cont` 和 v1 的数字来自[第二轮评测](../zh-kd-eval-20261117/report.md)，用的是同一个后端和同一批输入。

## 结论

- **四臂都没有取代 `kd-cont`，`vimeml-zh-v2-20m` 的候选仍是 `kd-cont`。**
  - 主指标是公开拼音集上用自身分数重打分（λ = 1.6）后的 Top-1：
    - `r3-plain` 54.8，`r3-data` 54.7，`r3-ctrl` 54.6，都与 `kd-cont` 的 54.8 持平（p ≥ 0.69）；
    - `r3-alpha` 53.5，显著低于 `kd-cont`（−1.4，p = 0.016）。
  - 替换的第二个条件是联想轨道 A 的 Top-3 达到 v1 的 27.6，四臂都没有达到，最高是 `r3-plain` 的 26.5。
  - 守门是 Standard 全拼重排，四臂都与 v1 持平（净 +1 到 +9，p ≥ 0.19）。
- **老师是 200M 时，20M 已经学到头。**
  - `r3-ctrl` 用 `kd-cont` 的配方多训 30,000 步，主指标没有变化（−0.2，p = 0.69）。
  - 加 r2 数据（`r3-data` 对 `r3-ctrl`）、加 plain（`r3-plain` 对 `r3-data`），主指标都不变。
- **α = 0.9 有害。** 更多地拟合老师，生成顺序和重打分都显著变差（对 `r3-data` 分别为 −1.2 和 −1.3）。
- **联想略有上升，但仍低于 v1。** 轨道 A 的 Top-3 从 25.6 升到 25.8–26.5，`r3-plain` 最高，与 v1 仍差 1.1。
- **后续安排：**
  - 第四轮用 `kd-cont` 的配方（只用 r1，α = 0.5，T = 1），只把老师换成 800M；
  - 错字计划里加不加 `typo` 的两臂，从 `kd-cont` 出发。

## 设置

- **四臂**（详见蒸馏计划第三轮）：
  - 都从 `kd-cont` final 出发，训练 30,000 步；
  - 峰值 LR 1e-4 → 1e-5，warmup 1000，seed `20261117`，老师是 12K 联合拼音 200M，T = 1。

  | 臂 | 每次更新的数据 | α | final.pt sha256 |
  | --- | --- | ---: | --- |
  | `r3-ctrl` | 只用 r1：plain 160 / full 96 / mixed 128 / initials 96 / error 32 | 0.5 | `b4b771f5…` |
  | `r3-data` | 每类 r1、r2 各一半，总量同上 | 0.5 | `f07d377c…` |
  | `r3-alpha` | 同 `r3-data` | 0.9 | `cc3d3160…` |
  | `r3-plain` | 同 `r3-data`，但 plain 是 256（r1 128 + r2 128） | 0.5 | `7cd2ce8d…` |

- **拼音生成**：公开集 `ime-pinyin-zh-v1` development，3,444 条输入。
  - 分桶束搜索，束宽 16，带输入框内的上下文，任务模式。
  - 取前 10 个候选，按 genScore + λ × prior 重排，λ = 1.6，prior 是模型自己。
- **配对检验**：句子簇 sign-flip，20,000 次置换。
- **Standard**：`ime-standard-zh-v1-r1` development 全拼重排，1,456 题。
- **联想**：`ime-predict-zh-v1-r1` development，轨道 A–D。

## 对 v2 的影响

- `vimeml-zh-v2-20m` 的候选不变，仍是 `kd-cont`，用自己的分数重打分，λ = 1.6。
- 发布说明里联想低于 v1 这一条不变。
- 第四轮用 `kd-cont` 的配方，只换老师（800M）。r2 数据不加：老师是 200M 时 r2 没有带来提升。
- 错字计划的两臂从 `kd-cont` 出发。
- 第三轮没有跑私有基准。
