# V4-C1r2 数据修订实验

2026-10-16 在原 RTX 4090 实例 完成 11 次转换集遍历、42,240 次更新，按转换验证 plateau 正常早停。最佳 Standard 条件评分为第 5 轮 step 19,200 的 473/728，末轮为 467/728；仍低于 V4-B 的 498/728 与 V2.1 的 505/728。该实验沿用 C1 任务协议，修订转换数据与 LM 保留策略，不属于 C2 Ranking 或教师蒸馏实验。

## 变更与实验边界

C1 首轮在第二轮结束触发 LM 保留保护，完整条件评分为 425/728。同一权重的普通 LM 评分为 486/728，空 READ 条件评分为 461/728。数据调查发现训练转换片段远短于实际输入，且目标专名、标点和数字覆盖不足。

C1r2 从同一个 V4-B step 584000 checkpoint 初始化新 AdamW，使用新的数据目录与输出目录。模型仍为固定 8K、15,070,848 参数、context 128；BF16、编译、batch 256 转换＋256 LM、loss 0.7/0.3、学习率 1e-4→1e-5、warmup 1%、最多 12 次转换集遍历保持原设置。样例数量改变使总步数与 warmup 的绝对步数发生变化。

辅助变更是 `lm_retention_policy = "monitor"`：完整 LM BPC、原 1% 资格判断及连续恶化次数继续记录，但不再据此中止训练或否决候选重排 checkpoint。`best-rerank.pt`/`best.pt` 依据既有 Standard 正确数、转换 NLL 和 step 排序选取；其 LM 保留资格必须查看对应完整评估记录，不能由文件名推断。转换 plateau 仍按相对累计改善 0.2%、patience 3 处理。

因此，本轮不是仅改变数据的严格单变量因果对照；数据、预算对应的实际曝光量及停止/选模策略均在记录中显式区分。

## 数据来源与规则

从已通过 C1 审核的母句清单按 parent hash 固定选择：训练 hash 模 100 小于 25 的母句生成扩展视图，25–34 保留已审核短视图，其余不参与本轮。验证母句中小于 72 的部分生成扩展视图，其余保留短视图。

扩展视图重新读取原冻结 TXT，以原文 byte offset、parent hash 和旧 span 确认来源；在母句原目标附近的有界区间中标注连续 8–48 字表记，读音最多 72 字，编码后仍受固定 128 预测位置约束。MeCab/UniDic 与 Sudachi 必须在共同原文边界上给出相同读音。已知专名不再直接排除，但未知或双路读音不一致的片段拒收。假名保留键盘正字法，数字、ASCII 与标点作为直接输入文字保留，READ 应用与推理一致的 NFKC／片假名转平假名；不猜测数字的日语口读法。原有单字复合边界与「家」歧义保护保留。

训练排除全部原始 validation 母句 hash、冻结转换验证任务及编码序列，并对已知非 blind 开发/回归样例作精确身份排除。没有使用开发集答案补样本或改标签；未读取 test/blind。双词典标签仍为 silver，不宣称母语人工 gold，也不宣称文档/语义级完全无重叠。继承记录中的 `stratum` 表示原 C1 母视图的采样层，修订后的实际分布以本轮 manifest histogram 为准。

最佳重排 checkpoint 的完整 BPC 为 3.198840913，较 V4-B 起点恶化约 5.65%；末轮／最佳 LM BPC 为 3.150786955，恶化约 4.06%。完整转换 NLL 的最优值为 0.167418942，末轮为 0.172468062。此次 validation 已改用新制作规则，NLL 不与原 C1 的 0.165634 作优劣排序。

最佳条件评分相对 AzooKey 新纠正 86 条、改坏 66 条，净增加 20 条；相对 C1 首轮第 2 轮 checkpoint 新纠正 92 条、损失 44 条，净增加 48 条；相对 V4-B 新纠正 53 条、损失 78 条，净减少 25 条。JMultiWOZ 为 206/245，V4-B 为 201；WRIME 为 267/483，V4-B 为 297。当前主要缺口仍在 WRIME，不能作为部署替换版本。

上述比较使用完全相同的 728 条冻结候选和参考答案。最佳轮次由该开发集选择，属于探索性结果，不是独立测试或确证性统计结论。单独将 473−425 全部归因于某一项数据修改不成立，因为训练曝光量和停止策略也发生了变化。

远端 `best-rerank.pt`／`best.pt` 对应第 5 轮，`best-conversion.pt` 对应第 8 轮，`best-lm.pt`／`last.pt` 对应第 11 轮。原始 summary、逐轮评分及下载身份保存在本地 `outputs/evaluation-v4-c1r2-20261016/`。

## 最佳 checkpoint 定向诊断

`best-rerank.pt` 已下载并核对 SHA256 `1db399d5a5002712e3dccced993de4aa5abf5cfd365d605c4b7bc3fc0a4801e4`，checkpoint step 为 19,200。在本地 RTX 5060 Laptop 使用 FP32、原固定 728 条候选、零训练更新得到：

| 评分路径 | 正确数 |
| --- | ---: |
| V4-B 普通 LM，既有结果 | 498/728 |
| C1r2 同一权重普通 LM | 478/728 |
| C1r2 完整 CTX/READ 条件评分 | 473/728 |
| C1r2 空 READ 条件评分 | 469/728 |
| C1r2 空 CTX 条件评分 | 468/728 |

完整条件评分复现远端 473/728，所有路径均无窗口回退。本轮 READ 净增益为 4 条，仍不足以证明独立、稳定的输入法收益；空 READ 在训练中约占 10%，不是独立训练的无读音对照。

原 C1 同一权重的普通 LM/完整条件评分分别为 486/425，条件接口带来的净差为 −61；修订后为 478/473，净差缩小为 −5。该变化支持条件数据修订有帮助的解释，但本轮普通 LM 排序仍比 V4-B 少 20 条，转换监督对语言排序能力的偏移仍然存在。不同评分路径不是可线性相加的因果分解，不能将 20/25 解释为某因素的精确贡献率。

修订已恢复数条此前错误的「札幌」「名古屋」表记，但人名及同音语义选择仍有错误；仅扩大通用转换片段覆盖未解决全部排序问题。结合第 5 轮排序峰值与第 8 轮转换 loss 最低点的分离，当前没有继续延长原转换目标训练的明确依据。下一步更值得研究训练集实际候选上的排序目标，并独立控制学习率和 LM 重放；不将该建议写成已验证有效的结论。
