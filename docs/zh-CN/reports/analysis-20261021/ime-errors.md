# IME Top-1 错误分解：瓶颈不在 LM 容量

2026-10-21。V4.3（加数据）和 V5（加大模型）都显著降低了 BPC，但 Top-1 没有改善（见 [V5 规模扩展](../../training-v5.md)）。本分析把六个模型在四个非 blind 集合上的全部 Top-1 错误逐题分类，找出剩余错误的来源。结论：Standard 上 V4.2 的 205 个错误中，48% 的参考答案不在候选池里，35–44% 是书写形式差异，明确的语义错误只有 17 个（8%）。模型规模能影响的只是这一小部分。

## 方法

只读取已完成的 FP32 重排分数（`scores.jsonl`），不运行模型，不读取 fixed reference 或 blind 集。入口为 [`analyze_ime_errors.py`](../../../../scripts/benchmarks/analyze_ime_errors.py)，结果在 `outputs/analysis-ime-errors-20261021/`。

每个错误的 Top-1 与最接近的参考答案比较，分为三类：

| 类别 | 判定 |
| --- | --- |
| 池外 | 冻结的 AzooKey 候选池（20 个）中没有任何参考答案，任何重排都无法答对 |
| 书写形式（A） | 同一组词，只是假名／汉字／片假名或送假名不同 |
| 语义（S） | 其余：同音异义、分词错误、专有名词 |

池中候选都由同一假名输入转换而来，读音相同，因此 A 与 S 的区别在于是否为同一组词。判定 A 采用保守规则：UniDic 词汇素序列相同（`fugashi` + `unidic-lite`，版本见 `requirements-evaluation.txt`），**并且**一方的汉字集合包含另一方。与此前 210 条 V2.1→V4.2 翻转的逐题标签对照：该规则从未把语义翻转判为 A（72/72），能识别 118/138 条书写翻转。只满足其中一条规则的情况另记为"A 上界"。

## 发现

1. **池外是最大的单项。** Standard、Legacy、AJIMEE 分别有 13%、11%、19% 的题目参考答案不在 20 个候选中。Standard 的 98 个池外题中，约 32 个模型选中了参考答案的书写变体（参考写法不在池里，但同义写法在）；其余约 66 个题，池中可能根本没有正确转换。这部分只能靠候选生成解决。
2. **池内错误以书写形式为主。** V4.2 在 Standard 的 107 个池内错误中，71–90 个是书写形式；Legacy 的 61 个池内错误中，57 个是书写形式、只有 4 个是语义错误。参考集合通常只收录一种写法，这类"错误"多数是风格差异，不是能力差异。
3. **LM 已经修复了绝大部分语义错误。** AzooKey 原排序在 Standard 有 59 个语义错误，所有 LM 都降到 14–26 个；AJIMEE 从 57 个降到 10–16 个。剩余的语义错误很少，因此 LM 质量的提升几乎没有可改进的对象。
4. **规模只在 AJIMEE 上显示出方向性收益。** V5 在 AJIMEE 的语义错误最少（11 个，V4.2 为 16 个），书写宽松口径净 +6，符合"更强的 LM 帮助百科领域同音词"的预期，但样本小，不显著。在对话类集合上，规模的效果被书写形式差异淹没；书写宽松口径下 V5 也没有优势。
5. **没有单一方向的平假名偏移。** Standard 上 A 类错误中，模型选择假名更多的写法的占约 40%（V4.2：28/71）；Legacy 为 58%（33/57），旧网页文本的参考答案偏好汉字。书写偏好更多取决于文体，而不是某个固定方向。
6. **多数错误不是"险负"。** 池内错误中只有约 25–35% 的对数概率差小于 1 nat，大部分错误是模型有把握地选了另一种写法。

## 对后续工作的含义

- **候选池覆盖率**是上限最高的方向：Standard 约 66 题、AJIMEE 约 35 题在池中找不到正确答案。需要在 Mac 端检查扩大 AzooKey N-best（例如 20 → 50）后覆盖率能提升多少。这需要重新生成候选，属于新的评测版本，必须先冻结再评分。
- **书写形式**应作为风格问题处理，而不是 LM 能力问题：可以作为客户端的用户偏好或文体先验，评测上则应在预注册后把书写宽松 Top-1 作为辅助指标同时报告。冻结的参考答案不因本分析修改。
- **打分改进（PMI、AzooKey 先验融合）**已按此协议完成，均未通过独立检验，见[免训练重打分](rescoring.md)。
- **继续扩大 LM 预训练的收益很小**：在对话类集合上，剩余的语义错误只剩十几个。如果要追求语义能力，AJIMEE 这类百科领域是唯一还有空间的地方，那属于领域数据问题。

## 局限

分类规则与此前 AI 逐题标签的一致率约 90%，不是人工母语标注；A 类是保守估计（漏判约 15%）。池外题目是否能通过扩大 N-best 找回，需要实际重新生成候选才能确定。所有数字来自反复使用过的开发／回归集，只用于诊断。
