# V4.2 LM／Chat 预训练评估

2026-10-20。V4.2 正常完成 20 轮、1,081,942 次更新。按完整 LM 验证 BPC 预先选出的最后一轮，在固定 Standard development 上达到 **523/728（71.84%）**，较 V2.1 增加 18 条、较 V4.1 的开发集最佳权重增加 14 条。旧网页和 AJIMEE 相对 V2.1 分别减少 4 条、5 条，尚未形成所有回归集合一致改善的结果。

本次下载训练记录、实际源码及 `best-lm.pt`，18 个文件共 183,647,412 字节，通过固定 Hugging Face revision、远端文件身份和发布校验和核对。原始记录保留在 `outputs/training-v42-20261020/`；本地四组 FP32 重排、配对结果和验收记录保留在 `outputs/evaluation-v42-20261020/`。没有读取 test/blind、调整参考答案或重新训练。

## 上下文与判断

V4.2 在 Standard 保留左文时为 523/728，清空左文时为 510/728；收益全部来自有左文的 407 条，分别为 281 与 268。AJIMEE 保留左文为 139，清空为 130；Legacy 为 370 与 369，Historical 为 123 与 124。上下文有实际收益，但依然随集合变化。

本次没有评估结构化 READ 路径；V4.2 本身未训练这一目标。没有新增联想能力的正式评测，也没有导出或运行 iOS 部署测试。

本轮比 V4.1 形成了更强的普通 LM 重排候选：主要开发集提高，普通 LM 和聊天验证也恢复改善。建议冻结当前第 20 轮，交由独立 benchmark 验证后再决定是否替换 V2.1（后续固定 reference 结果见[reference 与退化分析](reference-regressions.md)）；保留旧网页和 AJIMEE 的负向记录。当前数据不足以推荐直接切换正式部署，也不足以证明 Reading Conditioning 这一研究方向普遍无效。
