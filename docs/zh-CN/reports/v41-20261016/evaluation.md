# V4.1 混合预训练评估

2026-10-16。V4.1 正常完成 16 轮、865,557 次更新。普通 LM 重排在 Standard development 上最高为 509/728，较 V2.1 增加四条；旧网页和 AJIMEE 的结果存在取舍，当前不能据此认定可以替换部署模型。Reading 条件评分仍明显弱于同一权重的普通 LM 评分。

关键权重、完整训练状态、各轮评测、配置和实际源码已下载，178 个文件逐一通过远端／本地 SHA256 核对。后续分析在本地 RTX 5060 Laptop 完成，不再需要远端实例运行。没有关闭或释放实例，没有追加训练、读取 test/blind 或修改参考答案。

## 实验身份与比较范围

模型保留 8K、context 128、d384、七层、六头、SwiGLU 960，共 15,070,848 参数。使用操作系统随机生成并冻结的 seed 1219827974，从随机权重初始化 AdamW；完整十六轮 cosine 为 6e-4 至 6e-5，warmup 1,000 步。

训练包含原 FineWeb/Tatoeba、RealPersonaChat/MRMP，以及原文本派生的 C1r2 转换样例。聊天占实际 LM 监督 token 约 5%；两个目标独立按监督 token 归一化，loss 权重为 LM 0.8、转换 0.2。完整曝光为 9,683,477,884 个 LM 目标和 157,132,320 个转换目标。详细数据与配置见 [训练记录](../../training-v41.md)。

相对 V4-B，同时改变了数据、任务、seed 和预算，不能将差异单独归因于聊天、转换数据或轮数。本次不训练新模型，也不调整推理分数或筛题规则。

本地比较在查看新增回归结果前固定两个普通 LM 候选：Standard development 选出的第十三轮 `best-ordinary.pt` 为主候选，第十六轮 `last.pt` 为次候选。条件路径使用第十六轮 `best-rerank.pt`，其模型张量与 `last.pt` 相同。

## Reading 路径诊断

同一第十六轮权重、同一 Standard 候选与参考：

| 输入／评分路径 | 正确数 /728 |
| --- | ---: |
| 普通 LM，原左文 | **505** |
| 普通 LM，无左文 | 502 |
| 结构输入，保留 CTX、清空 READ | 502 |
| 结构输入，完整 CTX/READ | 461 |
| 结构输入，清空 CTX、保留 READ | 455 |

完整 READ 相对空 READ 改善 48 条、退化 89 条，净减少 41 条，描述性配对 p=0.000581。当前结构化 READ 路径在这批开发输入上产生负收益；与普通 LM 的差距不能简单解释为模型整体已经丧失排序能力。

这项消融同时改变输入长度、位置和内容；空 READ 本身也是约 10% 训练视图，不能据此单独定位为读音标签错误、位置分布或目标函数中的某一个机制，更不能推出 Reading Conditioning 普遍无效。

条件评分在 AJIMEE 有四条结构长度溢出，按原协议整条回退 AzooKey，保留全部 200 条分母；其他比较没有回退。四条回退不足以解释条件评分相对普通 LM 的整体差距。

## 联想与复现

在原固定十二个前缀上使用相同十六个新 token 预算、greedy／temperature 0.8、seed 42，只作定性观察。可生成「今日はとても暑いですね。」等自然延续，也仍有「明日の朝は、お弁当を食べました。」的时态冲突及「この本を読んで」后的重复。没有用这些例子给联想能力作正式排名。

本地全部使用未压缩 primitive FP32、关闭 TF32。普通评分沿用联合分词公共前缀后的完整词表 logP sum，无 EOS、不截断、稳定并列；条件评分只累加 OUT、不含 EOS。未调整长度归一化或融合系数。第十三轮普通、第十六轮普通及条件的 Standard 完整候选排序均逐题复现训练时记录。

完成十四组评估配置，共 6,151 个重复配置样例视图；这不是 6,151 个独立题目。逐条结果、配对、分项和参考身份检查通过，输入快照末尾重新核对固定 SHA256。
