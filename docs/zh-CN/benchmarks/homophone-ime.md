# 书面语同音词挑战集

2026-10-21。[错误分解](../reports/analysis-20261021/ime-errors.md)显示：对话类集合上的语义错误已降到十几条，剩余的语义差距集中在 AJIMEE 这类百科书面语，但 AJIMEE 只有 200 题，且来源公开。本集合专门测试书面语中的同音异义选择，冻结版本为 `ime-homophone-ja-v1-ai-expert`（release `b0dd1161…`），共 **619 题**。选择过程不使用任何模型；冻结前未导出候选、未评分。入口为 [`prepare_homophone_ime.py`](../../../scripts/benchmarks/prepare_homophone_ime.py)。

## 来源

日语 Wikipedia 2023-11-01 转储的一个分片（Hugging Face `wikimedia/wikipedia`，固定 revision `b04c8d1c`，`train-00014-of-00015`，即文章 ID 最新的分片，92,631 篇）。许可证 CC BY-SA 4.0，每题保留文章标题和 URL 以便署名。Wikipedia 不是直接训练来源，但网页语料可能含有转载。

## 构建

1. **同音组**：在该分片上用 UniDic 统计普通名词、动词、形容词。读音、词性、活用类型相同而词汇素不同的词组成一组；每个词汇素至少 2 字、在分片中至少出现 30 次；排除专有名词、数词、非自立动词和连浊读音。UniDic 词汇素相同视为书写变体（如 聞く/聴く），不算同音组，与书写宽松规则一致。共 1,924 组。
2. **区间**：在含同音组词的句子中，选取包含该词、6–20 字、起止都在词边界的转换区间，左文为同段落前文（最多 200 字，至少 10 字）。读音须由 UniDic 与 Sudachi 在独立与上下文两种情况下一致，与 Standard 的抽取规则相同。
3. **成对设计**：随机抽取 320 组，每组取出现最多的两个词汇素，各取一题，来自不同文章。因此总是选高频词的策略只能答对约一半。
4. **筛查**：句子对旧训练文本（25,185,368 行与 1,563,989 行）做完整包含或相似度 ≥ 0.85 检查，排除 14 条候选；与 AJIMEE 有任意 12 字重叠的排除 1 条。

| 统计 | 数值 |
| --- | ---: |
| 抽取通过的候选 | 14,260 |
| 草案 | 640（320 组；名词 606、动词 34；目标 6–10 字 417、11–20 字 223） |
| 审核剔除 | 21 |
| 读音修正 | 8 |
| 多个可接受表记 | 5 |
| 冻结 | **619**，320 组，其中 299 组两题都保留 |

## 审核

AI 逐题审核（`ai_expert`，非母语人工），检查读音、原文完整性，以及参考答案能否由左文和区间确定。剔除理由主要是：词典按另一个义项读音，例如佛教语境的"前世"读作 ゼンセ，因此不再与对立词同音（4 题）；人名、王族名读音无法确定或读错；原文缺失链接词或断句错误；古汉文与战前片假名法令文；区间起点切开了词。修正了 1 处原文错字（同读音）。可接受表记只在两种写法都通行时添加。

## 评分

评分按[确认评分计划 v2](confirmation-v2-plan.md)，已于 2026-10-21 使用，结果见[确认评分 v2 结果](confirmation-v2-results-20261021.md)。按 [指标 v2](metrics-v2.md)：精确 Top-1 与书写宽松 Top-1；诊断项为参考答案是组内高频词时与次高频词时的准确率，以及两题都答对的组数。统计以同音组为簇。候选池为 n-best 20，并列报告 n-best 50。

## 局限

- 只来自一个 Wikipedia 分片，文体为百科说明文；成对设计使高频词与次高频词各占一半，不代表真实使用中的分布。
- 标签为 AI 审核，不是母语人工 gold。
- 筛查未覆盖 V4.3 追加网页分片；Wikipedia 文本可能以转载形式出现在网页语料中。

题目文本、同音组清单与审核表只保存在本地忽略目录，不进入 Git。
