# IME 指标与统计 v2

2026-10-21 注册，策略文件为 [`configs/ime-metrics-v2.json`](../../../configs/ime-metrics-v2.json)。此后所有 IME 比较（包括任何新 blind 的首次评分）按此报告；此前冻结的结果保持原主指标，不追溯改写。背景见 [IME 错误分解](../reports/analysis-20261021/ime-errors.md)：Standard 剩余错误中池外约一半、书写形式约四成，单一的精确 Top-1 和逐题 McNemar 不足以判断模型差异。

## 指标

| 层级 | 指标 | 说明 |
| --- | --- | --- |
| 主指标 | 精确 Top-1 | 与 v1 相同：冻结可接受表记，完整分母（含池外） |
| 辅助 | 书写宽松 Top-1 | 精确命中，加上与池内参考答案为保守书写变体的选择（UniDic 词汇素序列相同**且**汉字集合包含），实现于 `vimeml.benchmarks.notation` |
| 辅助 | 池条件 Top-1 | 只计冻结候选池中含参考答案的题目 |
| 诊断 | 宽松上界、错误类别 | 只用于分析，不用于决策 |

候选池仍以 AzooKey n-best 20 为主（converter `d59a28e4`，typo/Zenzai 关闭）；n-best 50 在 v2 blind 与同音词集合上并列报告，切换主池需要新的指标版本。

## 统计

同一作者、同一对话用户或同一句型的题目往往同时翻转，逐题 McNemar 会高估证据。v2 以簇为单位检验：

- **主检验**：作者簇上的双侧配对 sign-flip 置换检验（WRIME 作者、JMultiWOZ 用户、Legacy 来源文档、同音词集合的同音组；其余每题一簇）。不一致簇不超过 20 个时精确枚举，否则 20,000 次固定种子抽样。
- **区间**：簇 bootstrap 的净差 95% 百分位区间（10,000 次，seed 0）。
- **敏感性**：句型簇（NFKC、数字掩码后字符三元组 Jaccard ≥ 0.5）以及作者与句型的并集。并集会把 Standard 链接成一个 185 题的大分量，因此只作敏感性分析，不作主簇。
- 逐题 McNemar 继续报告，便于与 v1 报告对照。

**判定规则**：声称 Top-1 改进需要主轨道精确 Top-1 净值 > 0 且作者簇检验 p < 0.05，并且任何报告轨道上书写宽松口径没有 p < 0.05 的退化。只有逐题 McNemar 显著不够。

实现为 [`statistics.py`](../../../src/vimeml/benchmarks/statistics.py)，报告入口为 [`report_ime_metrics.py`](../../../scripts/benchmarks/report_ime_metrics.py)，只读取已完成的 FP32 分数。

## 对既有结果的回溯描述

以下按 v2 口径重新计算已完成的非 blind 分数，结果在 `outputs/metrics-v2-20261021/summary.json`。这些集合都已反复使用，只用于说明统计口径的影响，不改变任何既有结论。

| 模型 | 精确 | 书写宽松 | 池条件 |

| V4.3 第 30 轮 | 519 | 588 | 0.824 |

| 对比（Standard） | 精确 增/减 | 逐题 p | 作者簇 p | 簇 bootstrap 95% | 设计效应 |

V2.1 → V4.2 在逐题检验下刚好显著，按作者簇则不显著（p = 0.081），与此前固定 reference 只多 6 条且不显著的结果一致。按 v2 判定规则，V4.2 不构成已证实的改进。其他配对比较在所有口径下都不显著。Legacy、AJIMEE 与历史 development 每题一簇，簇检验与逐题检验基本相同。

## 局限

书写宽松规则与此前 AI 逐题标签的一致率约 90%，不是母语人工判断。作者簇只能覆盖已知的来源分组，话题、wizard 与网页转载关系没有建模。
