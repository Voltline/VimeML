# Standard IME v2 blind

2026-10-21。v1 blind 已在 V2.1/V3 A 比较中消耗，此后的模型选择只用 development，缺少新的确认集合。v2 blind 用 v1 协议从同一草案池中未被选中的 blind 角色题目重新抽取，冻结版本为 `ime-standard-ja-v2-blind-ai-expert`（release `5bd7c490…`）。**冻结前后均未导出候选、未运行任何模型**；评分须在提交模型计划后一次性完成，并按 [指标 v2](metrics-v2.md) 报告。入口为 [`prepare_standard_ime_v2.py`](../../../scripts/benchmarks/prepare_standard_ime_v2.py)。

## 构建

v1 草案池在无 LM 分数、无候选覆盖的条件下，从 blind 角色的 WRIME 作者和 JMultiWOZ 用户中提取了 4,000 条转换区间，并已对旧训练文本完成重叠筛查（见 [Standard IME 基准](standard-ime.md)）。v1 只选用其中 750 条。

| 步骤 | 排除 |
| --- | ---: |
| v1 已选用文档（同一帖子／对话） | 750 |
| v1 训练文本重叠（沿用 v1 审计） | 2 |
| V4.1+ 聊天语料重叠（482,320 句；完整包含 3、相似度 ≥ 0.85 的 16） | 19 |
| 剩余可用 | 3,229 |
| 每作者／用户最多 20 条或重复 | 1,199 |
| 与已选目标的字符三元组 Jaccard ≥ 0.5（JMultiWOZ 句型族） | 45 |

在可用题中按 v1 的分层（有无左文 × 读音长度）轮转抽样，配额与 v1 相同：WRIME 500、JMultiWOZ 250，共 62 位作者／用户。与 v1 development 的作者／用户不相交，与 v1 development 的输入／左文对不重叠。

## 审核与冻结

750 条在看不到模型输出和候选的条件下逐条由 AI 审核（`ai_expert`，`native_japanese_review=false`）：

| 结果 | 数量 |
| --- | ---: |
| 剔除 | 21（WRIME 14、JMultiWOZ 7） |
| 读音修正 | 26 |
| 多个可接受表记 | 289 |
| 冻结 | **729**（WRIME 486、JMultiWOZ 243；有左文 518） |

剔除规则：区间起点落在被左文切开的词或名字内部；起点是读音依赖前一数字的量词（如人、月、泊、分、杯）；无法确定写法的私人姓名或店名；没有确定转换的玩笑写法。可接受表记只加入同读音、同词的自然写法，经 UniDic/Sudachi 读音核对；先前加入的 5 个读音实际不同的变体已在冻结前删除。

## 局限

- 标签是 AI 专家审核，不是母语人工 gold，可接受表记不穷尽。
- 作者／用户与已消耗的 v1 blind 同属 blind 角色，只保证不重用文档、消息和输入／左文对；作者文体并不独立于 v1 blind。
- 重叠筛查覆盖旧训练文本和聊天语料，未覆盖 V4.3 追加的网页分片（不在本地）。
- 来源独立采集不能证明文本从未进入网页训练语料。

候选导出见 [候选导出 v2](candidates-v2-handoff.md)。题目文本、审核表与候选只保存在本地忽略目录，不进入 Git。
