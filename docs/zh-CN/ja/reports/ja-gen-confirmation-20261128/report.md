## 观察

- **对 V4.2 的提升与开发集一致**：kana 宽松 Top-1 在开发集上 +18（529 对 511），test 上同样 +18（528 对 510），p 从 0.013 降到 0.0024。严格 Top-1 提升更大（+28）。口语 test 上对 V4.2 的提升更明显：宽松 +28，严格 +63。
- **c40 对 kd-cont 的严格 Top-1 增益在 test 上没有复现**：开发集 +12（p 0.032，4-seed 均值 +12.25），kana test 只有 +3（p 0.73），口语 test +7（p 0.27）。两个 test 上方向为正，但幅度和显著性都不足以支持“口语后训练提高写法一致率”的说法。
- **c40 在各项上不低于 kd-cont**：宽松 Top-1、Top-3、口语 band 都持平或略高。在两个 20M 之间，c40 不劣于 kd-cont；选它发布由预注册规则决定。
- **合并列表优于单独生成**：仅生成的宽松 Top-1（kana 69.33%，口语 73.50%）低于合并后的列表，最终结果靠 AzooKey N-best 与生成候选的合并加自重排。
